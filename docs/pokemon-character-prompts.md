# Pokémon character prompts

25 individual prompts for every remaining character in the current catalogue, excluding Pikachu because a reference image has already been supplied. Bulbasaur is included because its earlier request did not produce an image.

All 25 prompts were sent individually to Nano Banana 2 on 24 September 2026 with the supplied Pikachu as a style reference. The [generation record](pokemon-generation.json) includes the output settings and an additional correction to Charizard's tail. To regenerate, use each prompt as a separate request and attach the same Pikachu reference.

These prompts deliberately request a solid white background. Remove that background afterward to create genuine transparency; do not ask the image model to draw a transparency checkerboard.

The matching [JSON file](pokemon-character-prompts.json) contains the same complete prompts and suggested output filenames. See [background-removal.md](background-removal.md) for local batch removal.

## Magikarp

Suggested filename: `magikarp.png`

```text
Create one polished, hand-painted 3D storybook illustration for a children's typing-game collection. Softly sculpted forms, subtle painted texture, crisp readable silhouette, warm gentle studio lighting, rich cheerful colours and expressive eyes. Match the finish and friendly mood of the supplied Pikachu reference if one is attached, using it only as a style reference.

Show exactly one Pokémon in its recognisable classic design. Full body, centred in a square composition, generally in a three-quarter view. Keep its entire silhouette inside the frame with at least 8% clear margin; fit long tails, wings and antennae by adjusting the pose, never by cropping.

Use a completely plain, solid white background for later background removal. No checkerboard, scenery, ground plane, cast shadow, glow outside the silhouette, border, card frame, text, labels, logos, watermark or extra characters. Keep the silhouette clearly separated from the background. Produce one image only, never a collage or evolution sheet.

Subject: A cheerful Magikarp from Pokémon, a bright orange-red fish with large round eyes, cream lips, long golden whiskers, pale side fins and a golden crown-shaped dorsal fin. A lively swimming pose with its complete tail and every fin visible.
```
